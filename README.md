# WS Platform

**Development of a WorldSkills IT Software Solutions Training Platform with an Intelligent Competency Diagnostics Module Based on Behavioral Log Analysis**

A web platform for learning C# and preparing for WorldSkills *IT Software Solutions for Business* (Skill 09):
a C# course with server-checked exercises, past test projects with weighted criteria, and learning analytics
that will warn teachers early about learners at risk of dropping out.

> Diploma project, Software Engineering, Astana IT University, 2026–2027.

Project description, team and links: in progress (task "README completion").

## Setup, run, test
```bash
cd frontend
npm install
npm run dev      # http://localhost:5173
npm test
npm run build
```
